pagina web responsiva diseñada en torno a un ecomerce de mecanica que ofrece piezas de vehiculos y servicios de
mantencion y tunning para carreras.

utiliza bootstrap para la responsibidad de la pagina y diseño junto con css.
contiene un archivo ui.js el cual se encarga de generar el navbar principal para cada seccion del html y
genera tambien "cards" de productos de manera automatica recibiendo los datos desde una variable
constituida en el mismo archivo los cuales despliega unicamente en el archivo productos.html de manera automatica.

esta pagina corresponde al proyecto de desarrollo web y movil seccion 8480 unab sede antonio varas año 2026 segundo semestre.
